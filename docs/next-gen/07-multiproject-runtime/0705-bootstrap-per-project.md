# 0705 — Bootstrap в мультипроектном режиме

**Фаза:** P0 · **Оценка:** M · **Зависит от:** 0701, 0703
**Файлы:** `packages/application/src/bootstrap-service.ts`

## Задача
Привязать bootstrap к конкретному проекту и репозиторию из каталога вместо процесс-глобального
`allowedWritePaths[0]`.

## Критерии приёмки
- [ ] Корень репозитория берётся из `Repository`, а не из конфигурации процесса.
- [ ] Повторный bootstrap проекта не затирает существующее состояние без явного флага.
- [ ] `tests/bootstrap-service.test.ts` расширен на два проекта.

## Тесты
- Интеграция: bootstrap двух проектов на разных фикстурных репозиториях.
