# 0702 — Сервис жизненного цикла проекта

**Фаза:** P0 · **Оценка:** M · **Зависит от:** 0202, 0701
**Файлы:** `packages/application/src/projects/project-service.ts`

## Задача
Use-cases: создать проект (с репозиторием и начальным конфигом), поставить на паузу, возобновить,
архивировать, обновить конфиг (новая версия).

## Критерии приёмки
- [ ] Создание проекта идемпотентно по `(tenantId, projectId)`.
- [ ] Пауза не убивает активный прогон, но запрещает постановку новых (взаимодействие с 1003).
- [ ] Архивация запрещена при активных прогонах — явная ошибка.
- [ ] Все операции проходят RBAC и пишутся в audit log.

## Тесты
- Юнит + интеграция: пауза/возобновление, архивация с активным прогоном, версия конфига.
