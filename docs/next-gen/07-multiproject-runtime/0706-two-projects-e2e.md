# 0706 — E2E: два проекта, два провайдера (в т.ч. локальный)

**Фаза:** P0 · **Оценка:** M · **Зависит от:** 0604, 0701, 0705
**Файлы:** `tests/multiproject-two-projects.e2e.test.ts` (новый)

## Задача
Контрольный сценарий фазы P0 — «ворота» на выход из фазы.

## Сценарий
1. Создать тенанта, два репозитория-фикстуры, два проекта.
2. Зарегистрировать два провайдера: mock-облачный и mock-локальный (`egressClass: 'private'`).
3. Проекту A назначить routing на облачный, проекту B — на локальный.
4. Прогнать `run-cycle` в обоих проектах.
5. Проверить: состояния изолированы, evidence-цепочки независимы, `run_cost` содержит записи
   с правильными `provider_id`, ревизии не пересекаются.

## Критерии приёмки
- [ ] Тест зелёный в режиме кассет (без сети).
- [ ] Падение одного проекта не влияет на другой.
- [ ] Время выполнения теста < 60 c.
