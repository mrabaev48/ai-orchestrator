# 0106 — Адаптер bindScope: ScopedStateStore → StateStore

**Фаза:** P0 · **Оценка:** S · **Зависит от:** 0105
**Файлы:** `packages/state/src/bind-scope.ts` (новый)

## Контекст
Нужно перевести хранилище на скоуп, не трогая `packages/execution` (7 000 строк, максимум
инвариантов и тестов). Классический strangler-приём: тонкий адаптер, связывающий один скоуп.

## Задача
Реализовать `bindScope(store: ScopedStateStore, scope: TenantScope): StateStore`.

## Критерии приёмки
- [ ] Все методы `StateStore` делегируются со связанным скоупом.
- [ ] `Orchestrator`, `RoleRunner`, `TaskRunner` продолжают работать без изменений.
- [ ] Существующие тесты `tests/state-store.test.ts` проходят через адаптер поверх
      скоупированной in-memory реализации (после 0206).

## Тесты
- Контрактный набор: прогнать существующий сценарий состояния через `bindScope` и убедиться
  в идентичности поведения (включая `expectedRevision` и конфликты ревизий).

## Не входит
- Удаление `StateStore` — задача 2402 (после полной миграции потребителей).
