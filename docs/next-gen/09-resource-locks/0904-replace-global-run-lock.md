# 0904 — Замена глобальной блокировки прогона

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 0903
**Файлы:** `packages/execution/src/orchestrator.ts`

## Задача
Убрать `resource: 'global-run-cycle'` и брать вычисленный `ResourceClaim`.

## Критерии приёмки
- [ ] В однопроектном однозадачном режиме поведение идентично текущему (одна exclusive-заявка).
- [ ] Причина «не удалось захватить» указывает конкретный занятый ключ, а не абстрактный лок.
- [ ] Метрика `run_lock_contention_total` получает тег `resource_key`.
- [ ] `tests/lock-authority.test.ts` и chaos-набор зелёные.

## Тесты
- Интеграция: два прогона одного проекта на разных ветках идут параллельно;
  два прогона на одной ветке — последовательно.
