# 0906 — Property-тесты на отсутствие взаимных блокировок

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 0904, 0905
**Файлы:** `tests/locks/resource-claims.property.test.ts` (новый)

## Задача
Сгенерировать случайные наборы заявок от N конкурентных прогонов и проверить инварианты.

## Инварианты
- Ни один прогон не удерживает ресурс, помеченный exclusive другим прогоном.
- Отсутствие взаимных блокировок (все прогоны рано или поздно завершаются).
- Отсутствие «повисших» лиз после аварийного завершения (после TTL всё освобождается).

## Критерии приёмки
- [ ] ≥1000 случайных сценариев в прогоне теста, seed фиксируется при падении.
- [ ] Тест выполняется < 30 c на in-memory lock-store.

## Тесты
- Сам тест является артефактом.
