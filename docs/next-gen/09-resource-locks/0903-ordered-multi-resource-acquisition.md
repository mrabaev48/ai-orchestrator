# 0903 — Упорядоченный захват нескольких ресурсов

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 0902
**Файлы:** `packages/execution/src/leases/execution-lease-authority.ts`

## Задача
Расширить существующий `ExecutionLeaseAuthority` на набор ресурсов: захват в лексикографическом
порядке ключей, откат уже захваченных при неудаче, единый heartbeat на весь набор.

## Контекст
Механика лизы (fencing token, renew, requireValid, `lease-protected-state-store`) уже есть —
меняется только количество ресурсов и порядок.

## Критерии приёмки
- [ ] Захват всегда в отсортированном порядке → взаимных блокировок нет by construction.
- [ ] Частичный захват полностью откатывается (никаких «повисших» лиз).
- [ ] Heartbeat продлевает все лизы набора; провал любой — отмена прогона (как сейчас).
- [ ] `requireValid` проверяет весь набор.

## Тесты
- Юнит: откат при отказе второго ресурса; продление набора; истечение одной лизы из набора.
