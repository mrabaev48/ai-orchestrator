# 0902 — Планировщик заявок на ресурсы

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 0901
**Файлы:** `packages/execution/src/locks/claim-planner.ts`

## Задача
По типу прогона и задаче вычислить набор ресурсных заявок.

## Правила
| Вид работы | Ключи | Режим |
|---|---|---|
| Анализ/планирование/чтение | `repo:<id>` | shared |
| Изменение backlog | `project:<id>:plan` | exclusive |
| Мутация кода | `repo:<id>:branch:<base>` | exclusive |
| git worktree admin | `repo:<id>` | exclusive (короткая секция) |
| Внешнее действие (PR, трекер) | `external:<service>` | shared/exclusive по политике |

## Критерии приёмки
- [ ] Для read-only прогона не выдаётся ни одной exclusive-заявки.
- [ ] Набор заявок детерминирован для одинакового входа.
- [ ] Заявки видны в evidence прогона (диагностика «почему ждём»).

## Тесты
- Юнит: матрица «вид работы → заявки».
