# 2403 — Вывод синтетических ролей из продуктового пакета

**Фаза:** P4 · **Оценка:** S · **Зависит от:** 1610
**Файлы:** `packages/agents/src/default-roles.ts`, `tests/support/*`

## Контекст
`CoderRole` и `ReviewerRole` — детерминированные заглушки, живущие рядом с продуктовыми
реализациями. Риск случайного использования в проде существует, хотя конфиг это и запрещает
(`validateProductionRoleRuntimeConfig`).

## Задача
Перенести синтетические роли в тестовые фикстуры либо оформить как явных «demo-агентов»
с невозможностью использования при `roleProviderMode=production`.

## Критерии приёмки
- [ ] Продуктовый бандл не содержит заглушек, выдающих `changed: true` без реальных изменений.
- [ ] Локальный сценарий из README (`WORKFLOW_ROLE_PROVIDER_MODE=synthetic`) продолжает работать.

## Тесты
- Регрессия smoke-сценария из README; проверка отсутствия заглушек в продуктовой сборке.
