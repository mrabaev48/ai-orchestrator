# 2401 — Миграция v15: удаление журналов из снимка состояния

**Фаза:** P4 · **Оценка:** M · **Зависит от:** 0207 (все читатели переведены)
**Файлы:** `packages/core/src/project-state.ts`, `packages/state/src/postgres/migrations.ts`

## Контекст
Пока `ProjectState` носит `runStepLog`, `artifacts`, `policyDecisions`, `approvals`, `failures`,
`decisions`, каждая запись состояния переписывает всю историю целиком.

## Задача
Удалить журнальные массивы из снимка, оставив в состоянии только оперативные указатели
(активная задача, счётчики, dedup-указатели).

## Критерии приёмки
- [ ] Ни один потребитель не обращается к удалённым полям (проверка грепом в CI из 0207).
- [ ] Размер снимка перестал расти с числом шагов (замер на 1000 шагов).
- [ ] `assertProjectState` и baseline-инварианты обновлены и зелёные.
- [ ] Задокументирован путь отката (миграция необратима — нужен бэкап-чеклист в ранбуке).

## Тесты
- Регрессия всего набора; замер размера снимка до/после.
