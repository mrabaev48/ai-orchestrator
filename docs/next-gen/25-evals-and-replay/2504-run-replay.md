# 2504 — Воспроизведение прогона из evidence

**Фаза:** P4 · **Оценка:** L · **Зависит от:** 1612, 0310
**Файлы:** `packages/application/src/evals/replay.ts`

## Задача
Детерминированно повторить прошедший прогон: та же версия агента, тот же набор правил (1806),
те же ответы модели (кассеты) — для разбора инцидентов.

## Критерии приёмки
- [ ] Replay не выполняет реальных side-effects (принудительный `propose-only`).
- [ ] Расхождение с исходным прогоном локализуется до конкретного шага.
- [ ] Отсутствие кассеты или версии агента даёт явную ошибку, а не «похожий» прогон.

## Тесты
- Интеграция: прогон → replay → полное совпадение шагов; искусственное расхождение локализовано.
