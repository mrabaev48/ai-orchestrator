# 2503 — Регрессионный набор для агентов

**Фаза:** P4 · **Оценка:** M · **Зависит от:** 2502
**Файлы:** `tests/evals/agent-regression.test.ts`

## Задача
Ворота на публикацию: сравнение метрик версии агента с предыдущей опубликованной.

## Критерии приёмки
- [ ] Падение успеха более чем на заданный порог блокирует публикацию (или требует явного override).
- [ ] Рост стоимости более чем на порог помечается предупреждением.
- [ ] Отчёт «версия A против B» доступен в UI редактора агента (2306).

## Тесты
- Интеграция на кассетах: заведомо худшая версия агента отклоняется.
