# 2501 — Корпус фикстурных репозиториев

**Фаза:** P4 · **Оценка:** M · **Зависит от:** —
**Файлы:** `tests/fixtures/repos/*`, `tests/support/scratch-git-repo.ts`

## Задача
Набор эталонных задач на воспроизводимых репозиториях: «добавить эндпоинт», «починить падающий
тест», «обновить зависимость», «написать недостающие тесты», «отрефакторить модуль».

## Критерии приёмки
- [ ] Каждая фикстура детерминирована (фиксированный git-граф, без сети).
- [ ] У задачи есть машинно-проверяемый критерий успеха (тесты фикстуры зелёные, дифф в допустимых границах).
- [ ] Генерация фикстуры занимает < 2 c.

## Тесты
- Самотест корпуса: все фикстуры создаются и проверяются.
