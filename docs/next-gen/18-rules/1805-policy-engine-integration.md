# 1805 — Встраивание правил в policy engine

**Фаза:** P2 · **Оценка:** M · **Зависит от:** 1804
**Файлы:** `packages/core/src/execution-policy-engine.ts`, `packages/execution/src/gates/preflight-policy-gate.ts`

## Задача
Правила класса `enforced` вычисляются в существующих гейтах наряду с текущими проверками,
их решения персистятся как `ExecutionPolicyDecision`.

## Критерии приёмки
- [ ] Блокирующее правило останавливает действие до side-effect, а не после.
- [ ] Решение содержит `ruleId` — видно, какое правило сработало.
- [ ] Существующие тесты гейтов (`preflight`, `step`, `postflight`) зелёные.
- [ ] Правила не могут ослабить существующие проверки, только добавить ограничения.

## Тесты
- Интеграция: запись в запрещённый путь блокируется; `require_approval_for` создаёт запрос.
