# 1806 — Фиксация набора правил в evidence

**Фаза:** P2 · **Оценка:** S · **Зависит от:** 1802, 1612
**Файлы:** `packages/execution/src/persistence/run-step-recorder.ts`

## Задача
Записывать хеш эффективного набора правил (и, при изменении, сам набор) в evidence прогона,
чтобы поведение агента было объяснимо задним числом.

## Критерии приёмки
- [ ] По прогону восстановим точный набор правил, действовавших на момент исполнения.
- [ ] Хранение компактно: полный набор пишется один раз на прогон, шаги ссылаются на хеш.

## Тесты
- Интеграция: изменение правила между прогонами даёт разные хеши в evidence.
