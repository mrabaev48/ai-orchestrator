# 1803 — Инжекция guidance-правил в контекст

**Фаза:** P2 · **Оценка:** S · **Зависит от:** 1802, 1402
**Файлы:** `packages/capabilities/src/rules/guidance.ts`

## Задача
Поместить текстовые правила в стабильный (кэшируемый) префикс сообщений, с учётом бюджета
и релевантности путям задачи.

## Критерии приёмки
- [ ] Guidance-правила входят в блок, помеченный `cacheHint: 'stable_prefix'`.
- [ ] При нехватке бюджета отсекаются правила с наименьшим приоритетом, а не произвольные.
- [ ] Enforced-правила тоже показываются модели (чтобы она не тратила шаги на запрещённое),
      но их соблюдение не зависит от модели.

## Тесты
- Юнит: порядок, бюджет, стабильность префикса между шагами.
