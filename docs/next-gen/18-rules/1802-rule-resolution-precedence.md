# 1802 — Разрешение и приоритеты правил

**Фаза:** P2 · **Оценка:** M · **Зависит от:** 1801
**Файлы:** `packages/application/src/rules/resolve-rules.ts`

## Задача
Собрать эффективный набор правил для прогона: `org → project → agent → path`, сортировка по
`(level, priority)`, при равенстве побеждает более строгое.

## Критерии приёмки
- [ ] Разрешение детерминировано и не зависит от порядка выборки из БД.
- [ ] Отключённое правило (`enabled: false`) исключается на самом раннем этапе.
- [ ] Итоговый набор кэшируется на прогон (не пересчитывается на каждом шаге).

## Тесты
- Юнит: конфликт двух правил разных уровней; равный приоритет; отключение.
