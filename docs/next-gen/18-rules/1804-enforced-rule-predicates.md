# 1804 — Исполнение enforced-предикатов

**Фаза:** P2 · **Оценка:** M · **Зависит от:** 1801
**Файлы:** `packages/core/src/rules/evaluate-predicate.ts`

## Задача
Реализовать вычисление каждого предиката над контекстом действия (какой инструмент, какие пути,
сколько файлов, какие действия).

## Критерии приёмки
- [ ] Каждый предикат — чистая функция, покрытая тестами на 100% ветвей.
- [ ] Glob-сопоставление предсказуемо (одна библиотека/реализация, документированная семантика).
- [ ] Результат: `allow | require_approval | block` + причина, пригодная для показа человеку.

## Тесты
- Юнит-матрица по всем предикатам, включая граничные случаи (0 файлов, пустые globs).
