# 1404 — Сводка состояния v2 с бюджетом

**Фаза:** P2 · **Оценка:** M · **Зависит от:** 1401
**Файлы:** `packages/execution/src/runtime-utils.ts`

## Контекст
`summarizeState` формирует текстовую сводку без учёта размера; при росте backlog она будет
занимать всё больше контекста, вытесняя полезное.

## Задача
Сделать сводку многоуровневой: обязательное ядро (текущая веха, активная задача, здоровье репо)
и опциональные секции, включаемые по бюджету и релевантности.

## Критерии приёмки
- [ ] Размер сводки ограничен сверху и предсказуем.
- [ ] Ядро сводки не зависит от размера backlog.
- [ ] Формат остаётся человекочитаемым (используется в отладке).

## Тесты
- Юнит: состояние со 100 и с 5000 задач → сводка в пределах лимита.
