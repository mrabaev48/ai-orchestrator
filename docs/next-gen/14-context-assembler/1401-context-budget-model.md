# 1401 — Модель бюджета контекста

**Фаза:** P2 · **Оценка:** S · **Зависит от:** 0302
**Файлы:** `packages/capabilities/src/context/budget.ts`

## Задача
Рассчитать доступный бюджет входных токенов: `contextWindow − maxOutputTokens − резерв`,
с оценкой размера блоков до отправки.

## Критерии приёмки
- [ ] Оценка токенов приближённая, но консервативная (лучше недооценить объём доступного места).
- [ ] Для моделей с малым окном (локальные) резерв настраивается отдельно.
- [ ] Превышение бюджета обнаруживается до сетевого запроса, а не по ошибке `context_overflow`.

## Тесты
- Юнит: расчёт на разных окнах; поведение при нулевом остатке.
