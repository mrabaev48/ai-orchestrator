# 1403 — Приоритеты вытеснения при нехватке бюджета

**Фаза:** P2 · **Оценка:** M · **Зависит от:** 1402, 1304
**Файлы:** `packages/capabilities/src/context/eviction.ts`

## Задача
Реализовать вытеснение снизу вверх по списку из 1402 с прозрачной диагностикой.

## Критерии приёмки
- [ ] Каждое вытеснение фиксируется (что и сколько токенов убрано) — попадает в evidence.
- [ ] Если после вытеснения всего вытесняемого бюджет всё ещё превышен — явная ошибка
      `context_overflow` до запроса, с рекомендацией (модель с большим окном / разбить задачу).
- [ ] Наблюдения никогда не теряются в evidence — только в контексте модели.

## Тесты
- Юнит: сценарии нехватки 10% / 50% / 200% бюджета.
