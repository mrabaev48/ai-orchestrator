# 2206 — Диагностика «почему ничего не происходит»

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 1003, 0902
**Файлы:** `apps/dashboard-api/src/diagnostics/stall.controller.ts`

## Контекст
Главный эксплуатационный вопрос автономной системы — «почему прогон стоит». Сегодня ответ
приходится собирать из логов.

## Задача
Эндпоинт `GET /api/v1/projects/{id}/diagnostics`, отвечающий одним ответом: причина простоя
(`SchedulingBlockReason`), занятые ресурсные ключи и их владельцы, состояние бюджета,
ожидающие approvals, состояние провайдеров, глубина очереди.

## Критерии приёмки
- [ ] Ответ формируется одним набором запросов, без сканирования журналов.
- [ ] Для каждой причины есть конкретное указание, что сделать.
- [ ] Эндпоинт доступен и в CLI (`check-state` дополняется секцией диагностики).

## Тесты
- Интеграция: каждая причина простоя воспроизводится и корректно репортится.
