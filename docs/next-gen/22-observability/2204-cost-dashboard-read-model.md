# 2204 — Read-модель экономики

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 0606
**Файлы:** `packages/application/src/read-models.ts`, `apps/dashboard-api/src/dashboard-query/*`

## Задача
Агрегаты для дашборда: стоимость по проектам/агентам/моделям за период, стоимость смерженного
PR, доля оценочных данных, доля кэшированных токенов.

## Критерии приёмки
- [ ] Каждый агрегат — один индексированный запрос, без выборки построчно.
- [ ] Ответ содержит явную пометку доли `estimated`-записей (честность данных).
- [ ] Период и группировка задаются параметрами с разумными лимитами.

## Тесты
- Интеграция на 100k строк `run_cost`: время ответа в пределах порога.
