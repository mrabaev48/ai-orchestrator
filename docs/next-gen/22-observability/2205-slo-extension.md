# 2205 — Расширение SLO/алертов на новые компоненты

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 0807, 2202
**Файлы:** `packages/application/src/slo/slo-policy.ts`, `.../slo-alerts.ts`

## Новые SLI
- Доля прогонов, взятых из очереди в пределах N секунд.
- Доля LLM-запросов, завершившихся без fallback.
- Доля прогонов без вмешательства человека.
- Доступность провайдеров моделей (по health).
- Доля merge-конфликтов от общего числа интеграций.

## Критерии приёмки
- [ ] Пороговые значения — данные, а не константы в коде.
- [ ] Алерты идут через существующий контур (`slo-alerts`) и в уведомления (2004).
- [ ] Ранбук (`docs/runbooks/autonomous-incidents.md`) дополнен новыми сценариями.

## Тесты
- Юнит на вычисление каждого SLI; интеграция на срабатывание алерта.
