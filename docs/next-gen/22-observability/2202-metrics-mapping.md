# 2202 — Маппинг внутренних метрик в OTel

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 2201, 0608, 0807
**Файлы:** `packages/execution/src/telemetry.ts`

## Задача
Транслировать существующие counters/histograms/gauges в OTel-инструменты, не меняя внутренний
`ObservabilityStore` (он остаётся источником для read-моделей).

## Критерии приёмки
- [ ] Имена метрик соответствуют семантическим соглашениям (единицы в имени, `_total` для счётчиков).
- [ ] Кардинальность тегов проверяется на этапе записи (запрет `runId`/`taskId` в тегах).
- [ ] Двойная запись (внутренний стор + OTel) не удваивает стоимость записи в БД.

## Тесты
- Юнит на маппинг; интеграция: набор метрик после прогона.
