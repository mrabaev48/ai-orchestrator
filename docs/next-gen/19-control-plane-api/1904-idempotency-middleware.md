# 1904 — Idempotency-Key для мутирующих запросов

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 1901, 0804
**Файлы:** `apps/dashboard-api/src/write/idempotency.middleware.ts`

## Задача
Все POST/PUT/PATCH принимают `Idempotency-Key`; повтор с тем же ключом возвращает исходный
результат, а не выполняет действие второй раз.

## Критерии приёмки
- [ ] Хранение результатов с TTL; конфликт (тот же ключ, другое тело) → 409.
- [ ] Механика опирается на существующий dedup-реестр домена, а не на новый.
- [ ] Запуск прогона через API дважды с одним ключом создаёт один элемент очереди.

## Тесты
- E2E: повтор запроса, конфликт тела, истечение TTL.
