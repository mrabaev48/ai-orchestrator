# 1901 — Разделение API на read и write модули

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 0702
**Файлы:** `apps/dashboard-api/src/dashboard-api.module.ts`, `apps/dashboard-api/src/write/*`

## Контекст
Сегодня API — read-модель плюс два write-эндпоинта approvals
(`apps/dashboard-api/src/dashboard-query/dashboard-query.controller.ts`). Управлять проектами,
агентами и провайдерами по HTTP нельзя.

## Задача
Ввести отдельный модуль записи с собственными guard'ами, оставив read-часть без изменений.

## Критерии приёмки
- [ ] Read-эндпоинты не изменили контракты (регрессия `tests/dashboard-api.e2e.test.ts`).
- [ ] Write-модуль подключается флагом (можно поднять чисто читающий инстанс).
- [ ] Версионирование путей: `/api/v1/...` для нового, старые пути сохраняются.

## Тесты
- E2E: запуск с включённым и выключенным write-модулем.
