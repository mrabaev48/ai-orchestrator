# 1910 — OpenAPI-контракт и контрактные тесты

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 1905, 1906, 1907, 1908, 1909
**Файлы:** `apps/dashboard-api/src/openapi.ts`, `docs/api/openapi.json`

## Задача
Сгенерировать и зафиксировать спецификацию; проверять совместимость в CI.

## Критерии приёмки
- [ ] Спецификация генерируется из DTO, а не пишется руками.
- [ ] Изменение, ломающее контракт, падает в CI (diff против зафиксированной версии).
- [ ] Спецификация опубликована в репозитории и используется UI (группа 23).

## Тесты
- CI-шаг сравнения спецификаций; smoke-запросы по каждому пути.
