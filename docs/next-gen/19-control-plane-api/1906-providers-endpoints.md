# 1906 — Эндпоинты провайдеров и моделей

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 1901, 0505
**Файлы:** `apps/dashboard-api/src/write/providers.controller.ts`

## Эндпоинты
```
POST   /api/v1/providers               регистрация (секрет в теле, только по HTTPS)
POST   /api/v1/providers/{id}/test     health + дискавери моделей
POST   /api/v1/providers/{id}/refresh  обновить каталог моделей
PATCH  /api/v1/providers/{id}          enable/disable, лимит конкурентности
DELETE /api/v1/providers/{id}
GET    /api/v1/models                  агрегированный каталог с health и ценами
```

## Критерии приёмки
- [ ] Секрет никогда не возвращается в ответах, только отпечаток.
- [ ] Регистрация локального провайдера возможна без секрета.
- [ ] Удаление провайдера, используемого в routing-правилах, отклоняется с указанием правил.

## Тесты
- E2E: полный цикл регистрации локального провайдера; отсутствие секрета в ответах и логах.
