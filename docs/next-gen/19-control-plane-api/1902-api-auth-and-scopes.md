# 1902 — Аутентификация: API-ключи и JWT-скоупы

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 1901, 0503
**Файлы:** `apps/dashboard-api/src/security/*`

## Контекст
Есть проверка HS256-JWT (`apps/dashboard-api/src/security/jwt.ts`) и middleware. Для сервисных
интеграций (CI, webhooks) нужны ключи, для людей — токены со скоупами.

## Объём
- Сервисные API-ключи: хранение хеша, префикс для идентификации, ротация, отзыв.
- Скоупы: `projects:read`, `projects:write`, `agents:write`, `runs:write`, `approvals:decide`,
  `providers:write`, `admin`.
- Привязка субъекта к тенанту — каждый запрос обязан быть скоупирован.

## Критерии приёмки
- [ ] Запрос без нужного скоупа → 403 с указанием требуемого скоупа.
- [ ] Ключ хранится только в виде хеша; при создании показывается один раз.
- [ ] `tests/dashboard-api.security.e2e.test.ts` расширен.

## Тесты
- E2E: доступ по ключу, по JWT, отказ по скоупу, отозванный ключ.
