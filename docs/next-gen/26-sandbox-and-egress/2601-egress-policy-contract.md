# 2601 — Контракт egress-политики

**Фаза:** P4 · **Оценка:** S · **Зависит от:** 0302
**Файлы:** `packages/core/src/security/egress-policy.ts`

## Контракт
```ts
export interface EgressPolicy {
  readonly mode: 'deny_all' | 'allow_list' | 'unrestricted';
  readonly allowedHosts: readonly string[];   // провайдеры моделей, git-хост, реестры пакетов
}
```

## Критерии приёмки
- [ ] Политика разрешается на уровне проекта и может только сужаться агентом.
- [ ] Дефолт для нового проекта — `allow_list` с пустым списком плюс явно разрешённые провайдеры.
- [ ] Проверка применима и к HTTP-инструментам, и к MCP, и к webhooks.

## Тесты
- Юнит: разрешение/запрет хоста; сужение политики агентом.
