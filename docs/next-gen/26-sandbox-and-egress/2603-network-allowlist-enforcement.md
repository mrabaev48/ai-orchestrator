# 2603 — Принуждение сетевого allow-list

**Фаза:** P4 · **Оценка:** L · **Зависит от:** 2601, 2602
**Файлы:** `packages/execution/src/security/egress-guard.ts`

## Задача
Применять egress-политику на всех исходящих путях: LLM-провайдеры, HTTP-инструменты,
MCP over HTTP, webhooks, git remote, установка зависимостей.

## Критерии приёмки
- [ ] Запрос к неразрешённому хосту блокируется до установления соединения и попадает в audit.
- [ ] Защита от SSRF: запрет приватных диапазонов по умолчанию, резолв DNS проверяется
      (защита от rebinding).
- [ ] В контейнерном режиме политика дополнительно обеспечивается сетевыми правилами, а не только кодом.

## Тесты
- Юнит: allow/deny по хосту; интеграция: попытка обращения к приватному IP отклонена.
