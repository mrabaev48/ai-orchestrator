# 2604 — Профиль offline (полностью локальный контур)

**Фаза:** P4 · **Оценка:** M · **Зависит от:** 2603, 0403
**Файлы:** `packages/application/src/security/offline-profile.ts`

## Задача
Режим, в котором код гарантированно не покидает периметр: `EgressPolicy.mode = 'deny_all'`
плюс разрешение только провайдеров с `egressClass: 'private'`.

## Критерии приёмки
- [ ] В offline-профиле регистрация публичного провайдера отклоняется, а существующие отключаются.
- [ ] Прогон в offline не делает ни одного внешнего запроса (проверяется перехватом сетевого слоя в тесте).
- [ ] Профиль виден в UI и в диагностике проекта.

## Тесты
- Интеграция: полный цикл на локальной модели без единого внешнего соединения.
