# 0604 — Реальный выбор модели по роли/агенту

**Фаза:** P0 · **Оценка:** M · **Зависит от:** 0602, 0309
**Файлы:** `packages/execution/src/roles/role-runner.ts`, `packages/runtime/src/index.ts`

## Контекст
Расхождение конфига и поведения: `resolveModelForRole` вычисляет модель только для метрик и
расчёта стоимости; запрос всегда уходит в модель по умолчанию.

## Задача
Передавать разрешённый `modelRef` в gateway, чтобы роль действительно исполнялась выбранной моделью.

## Объём
- `RoleGenerationPort` получает `modelRef` (или резолвер) вместо предсоздания клиента.
- `createProductionRoleRegistry(llmClient)` → принимает gateway и routing-политику.
- Метрика `llm_model_selection_total` остаётся, но теперь отражает фактический выбор.

## Критерии приёмки
- [ ] Тест: `LLM_ROLE_MODELS={"coder":"A","reviewer":"B"}` приводит к двум разным реальным вызовам.
- [ ] Поведение по умолчанию (одна модель на всё) не изменилось.
- [ ] `tests/runtime-config.test.ts` и role-тесты зелёные.

## Тесты
- Интеграция с mock-провайдером: проверка фактического `modelRef` в каждом вызове.
