# 0605 — Учёт токенов по фактическому usage

**Фаза:** P0 · **Оценка:** M · **Зависит от:** 0301, 0604
**Файлы:** `packages/execution/src/roles/role-runner.ts`

## Контекст
`RoleRunCostTracker` считает токены эвристикой `estimateObservationTokens`
(`role-runner.ts:164,180,217`), поэтому бюджеты и стоимость систематически неточны.

## Задача
Перевести трекер на фактический `usage` из `ChatResponse`, оставив эвристику как явный fallback.

## Критерии приёмки
- [ ] Если `usage.estimated === false`, эвристика не применяется.
- [ ] Метрики получают тег `estimated=true|false` — видно долю оценочных данных.
- [ ] Кэшированные токены учитываются отдельно и по своей цене.
- [ ] Существующие бюджетные ошибки (`WorkflowPolicyError` с `budgetType`) сохраняют формат.

## Тесты
- Юнит: провайдер с usage и без; кэш-хиты; превышение бюджета на фактических токенах.
