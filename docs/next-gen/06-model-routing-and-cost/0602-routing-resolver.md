# 0602 — Резолвер маршрутизации с ограничениями и здоровьем

**Фаза:** P0 · **Оценка:** M · **Зависит от:** 0601, 0405
**Файлы:** `packages/llm/src/routing/resolver.ts`

## Задача
По `(agent, roleKey, stage, требуемые возможности)` вернуть упорядоченный список пригодных
`modelRef` с учётом ограничений, capability-матрицы и health-статуса провайдера.

## Критерии приёмки
- [ ] Модель без tool-calling отсеивается, если запрос требует инструментов.
- [ ] Модель с `contextWindow` меньше требуемого отсеивается до отправки запроса.
- [ ] `egressClass: 'private'` жёстко ограничивает выбор локальными провайдерами.
- [ ] Причина отсева каждого кандидата доступна для диагностики.

## Тесты
- Юнит: матрица ограничений; отсутствие пригодных кандидатов; деградация по health.
