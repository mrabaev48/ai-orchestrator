# 0603 — Исполнитель цепочки fallback

**Фаза:** P0 · **Оценка:** M · **Зависит от:** 0602, 0305, 0306
**Файлы:** `packages/llm/src/routing/fallback.ts`

## Задача
Выполнить запрос по первому кандидату; при retriable-ошибке — ретраи внутри кандидата;
при исчерпании — переход к следующему с фиксацией причины.

## Критерии приёмки
- [ ] Не-retriable ошибки (`auth`, `content_filter`) не приводят к бессмысленному перебору
      всех кандидатов одного провайдера, но переключение на другого провайдера допускается.
- [ ] `context_overflow` не ретраится, а поднимается наверх (лечится урезанием контекста, 1404).
- [ ] Метрика `llm_fallback_total{from_model, to_model, reason}`.
- [ ] Итоговая ошибка содержит историю попыток.

## Тесты
- Юнит: успех на втором кандидате; отказ всех; отмена в середине цепочки.
