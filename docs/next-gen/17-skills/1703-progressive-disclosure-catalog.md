# 1703 — Каталог скиллов и прогрессивное раскрытие

**Фаза:** P2 · **Оценка:** M · **Зависит от:** 1701, 1402
**Файлы:** `packages/capabilities/src/skills/catalog.ts`

## Контекст
Если положить тела всех скиллов в системный промпт, контекст локальной модели закончится
до начала работы. Поэтому в контекст идёт только каталог.

## Задача
Формировать компактный каталог `name + description` с учётом релевантности задаче и бюджета токенов.

## Критерии приёмки
- [ ] Каталог не превышает заданный бюджет токенов; лишние скиллы отсекаются по релевантности.
- [ ] Ранжирование детерминировано (совпадение по `triggers` + модулям задачи), без вызова LLM.
- [ ] Пустой каталог не ломает промпт.

## Тесты
- Юнит: 20 скиллов → каталог в бюджете; стабильность ранжирования.
