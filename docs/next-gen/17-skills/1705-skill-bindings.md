# 1705 — Привязка скиллов к агенту и проекту

**Фаза:** P2 · **Оценка:** S · **Зависит от:** 1701, 1502
**Файлы:** `packages/application/src/capabilities/bindings.ts`

## Задача
Управление `capability_bindings`: какие скиллы доступны агенту, какие — всем агентам проекта.

## Критерии приёмки
- [ ] Итоговый набор = скиллы проекта ∪ скиллы агента, с дедупликацией по `skillId`.
- [ ] Привязка к несуществующему скиллу отклоняется при публикации агента (1606).
- [ ] Изменение привязки не влияет на уже запущенные прогоны.

## Тесты
- Юнит: объединение наборов; конфликт версий одного скилла; неизвестный скилл.
