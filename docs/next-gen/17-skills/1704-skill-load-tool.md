# 1704 — Инструмент skill_load

**Фаза:** P2 · **Оценка:** S · **Зависит от:** 1703, 1202
**Файлы:** `packages/capabilities/src/skills/skill-load-tool.ts`

## Задача
Дать агенту явный инструмент загрузки тела скилла по идентификатору — это и есть механика
прогрессивного раскрытия.

## Критерии приёмки
- [ ] Класс риска `read`; approval не требуется.
- [ ] Повторная загрузка того же скилла в рамках прогона отдаётся из кэша и не тратит токены дважды.
- [ ] Загрузка отражается в evidence (видно, каким знанием пользовался агент).

## Тесты
- Юнит: загрузка, повтор, неизвестный скилл, превышение бюджета контекста.
