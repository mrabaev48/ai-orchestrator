# 1702 — Загрузчик скиллов и lock-файл с чек-суммами

**Фаза:** P2 · **Оценка:** M · **Зависит от:** 1701
**Файлы:** `packages/capabilities/src/skills/loader.ts`

## Задача
Загружать скиллы из inline/git/registry, проверять целостность по checksum и отклонять подмену.

## Объём
- Формат lock-файла по образцу `skills-lock.json` (source, sourceType, computedHash).
- Проверка хеша при каждой загрузке; несовпадение → отказ и запись в audit.
- Кэш распакованных ресурсов на диске с TTL.

## Критерии приёмки
- [ ] Подмена содержимого источника обнаруживается и блокирует использование скилла.
- [ ] Загрузка из git выполняется без исполнения кода из репозитория скилла.
- [ ] Ошибка загрузки одного скилла не ломает прогон — он просто недоступен, с предупреждением.

## Тесты
- Юнит: корректный хеш, подменённый хеш, недоступный источник.
