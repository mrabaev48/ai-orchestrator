# 2307 — Экраны capabilities и экономики

**Фаза:** P3 · **Оценка:** L · **Зависит от:** 1906, 1908, 2204
**Файлы:** `apps/web/src/pages/{providers,capabilities,cost}/*`

## Объём
- Провайдеры: список с health, моделями, ценами; мастер добавления локального провайдера
  (адрес → тест → обнаруженные модели → сохранить).
- MCP-серверы: подключение, тест, список инструментов с классами риска.
- Правила и скиллы: списки, редакторы, симуляция правила на прошлом прогоне.
- Экономика: стоимость по проектам/моделям/агентам, доля кэша, доля оценочных данных.

## Критерии приёмки
- [ ] Секреты вводятся, но никогда не отображаются обратно.
- [ ] Класс риска MCP-инструмента виден до его включения.
- [ ] Графики читаемы в светлой и тёмной теме.

## Тесты
- Компонентные тесты на каждый экран с mock-API.
