# 2302 — Экраны проектов и прогонов

**Фаза:** P3 · **Оценка:** L · **Зависит от:** 2301, 1905, 1909
**Файлы:** `apps/web/src/pages/{projects,runs}/*`

## Объём
- Список проектов: статус, автономия, активные прогоны, бюджет за сутки, здоровье репозитория.
- Карточка проекта: backlog, вехи, последние прогоны, диагностика простоя (2206).
- Список прогонов с фильтрами; карточка прогона: статус, стоимость, шаги.

## Критерии приёмки
- [ ] Список проектов открывается за один запрос (без N+1 к API).
- [ ] Причина простоя проекта видна на первом экране, без перехода в логи.

## Тесты
- Компонентные тесты на mock-API; проверка отсутствия N+1.
