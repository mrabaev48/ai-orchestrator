## Объём
- Форма определения: инструкции, выходная схема, инструменты, MCP, skills, rules, модель, лимиты, политика.
- Отчёт валидации с указанием конкретных полей.
- Кнопка dry-run и просмотр трейса пробного прогона.
- Diff между версиями агента и история публикаций.

## Критерии приёмки
- [ ] Публикация недоступна при ошибках валидации; ошибки показаны у соответствующих полей.
- [ ] Попытка расширить права проекта отображается как отдельная блокирующая ошибка со ссылкой на правило.
- [ ] Редактор работает и с YAML-представлением (для тех, кто хранит агентов в git).

## Тесты
- Компонентные тесты; e2e: создание → валидация → dry-run → публикация.
