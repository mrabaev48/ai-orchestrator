# 2303 — Живой таймлайн прогона

**Фаза:** P3 · **Оценка:** L · **Зависит от:** 2002, 2302
**Файлы:** `apps/web/src/pages/runs/timeline/*`

## Задача
Показывать шаги прогона в реальном времени через SSE: роль, инструмент, длительность, статус,
стоимость шага, решения политики.

## Критерии приёмки
- [ ] Переподключение после разрыва не теряет и не дублирует события (`Last-Event-ID`).
- [ ] Длинный прогон (500 шагов) не тормозит интерфейс (виртуализация списка).
- [ ] Секреты и содержимое инструментов, помеченное как чувствительное, скрыто по умолчанию.

## Тесты
- Компонентные тесты с фиктивным SSE-потоком; сценарий разрыва.
