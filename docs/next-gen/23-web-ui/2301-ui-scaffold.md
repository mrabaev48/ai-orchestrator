# 2301 — Каркас веб-приложения

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 1910
**Файлы:** `apps/web/*` (новое приложение в workspace)

## Задача
Поднять фронтенд-приложение в монорепозитории с типизированным клиентом, сгенерированным из
OpenAPI (2101/1910), и с авторизацией по JWT/API-ключу.

## Критерии приёмки
- [ ] Клиент API генерируется из спецификации, а не пишется руками.
- [ ] Приложение включено в turbo-пайплайн (`lint`, `typecheck`, `build`) и в проверку границ пакетов.
- [ ] Никаких прямых обращений к БД и к пакетам домена — только HTTP.

## Тесты
- Сборка в CI; smoke-тест рендера с mock-API.
