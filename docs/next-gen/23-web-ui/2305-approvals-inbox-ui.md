# 2305 — Inbox approvals

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 1909, 2304
**Файлы:** `apps/web/src/pages/approvals/*`

## Задача
Очередь решений с контекстом: что именно просит агент, какое правило/риск это вызвало,
дифф и доказательства, срок SLA.

## Критерии приёмки
- [ ] Решение принимается за один экран, без перехода в другие разделы.
- [ ] Просроченные и близкие к просрочке выделены (данные из существующего SLA-движка).
- [ ] Действие требует явного подтверждения и записывает актора в audit.

## Тесты
- Компонентные тесты; e2e: approve → прогон продолжается.
