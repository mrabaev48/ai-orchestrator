# 2104 — Синхронизация статусов PR и комментариев ревью

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 2102
**Файлы:** `packages/application/src/hosting/pr-sync-service.ts`

## Задача
Подтягивать состояние PR (проверки CI, ревью, конфликты) в состояние проекта, чтобы агент и
оператор видели актуальную картину.

## Критерии приёмки
- [ ] Статус PR отражается в backlog-задаче и в read-моделях.
- [ ] Провал CI создаёт задачу/событие для реакции агента (связка с 2105).
- [ ] Опрос не превышает лимиты API (адаптивный интервал + webhooks как основной путь).

## Тесты
- Интеграция: смена статуса на фиктивном хостинге → обновление состояния.
