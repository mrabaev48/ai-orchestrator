# 2103 — Адаптер GitLab

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 2101
**Файлы:** `packages/tools/src/hosting/gitlab.ts`

## Объём
- Merge requests API: создание, обновление, комментарии, статусы пайплайна.
- Учесть отличия семантики: MR вместо PR, `draft:` в заголовке, разные состояния пайплайна.
- Поддержка self-hosted инстансов (кастомный `baseUrl`) — важно для закрытых контуров.

## Критерии приёмки
- [ ] Тот же порт, те же гарантии идемпотентности и approvals.
- [ ] Self-hosted URL проходит egress-политику.

## Тесты
- Юнит на фикстурах; интеграция с фиктивным сервером.
