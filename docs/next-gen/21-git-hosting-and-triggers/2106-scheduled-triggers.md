# 2106 — Запуск по расписанию

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 0802, 1003
**Файлы:** `packages/application/src/triggers/schedule-service.ts`

## Задача
Cron-подобные расписания на проект: ночной прогон tech-debt агента, еженедельный аудит
зависимостей, регулярная проверка готовности релиза.

## Критерии приёмки
- [ ] Расписание хранится как данные, с таймзоной проекта.
- [ ] Пропуск окна (процесс был выключен) не порождает лавину догоняющих запусков —
      максимум один догоняющий, поведение настраивается.
- [ ] Идемпотентность по окну расписания (одно окно — один прогон, даже при N инстансах планировщика).

## Тесты
- Юнит с управляемым временем: обычный запуск, пропуск окна, конкурентные планировщики.
