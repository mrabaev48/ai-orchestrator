# 2105 — Входящие webhook-триггеры

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 1904, 0802
**Файлы:** `apps/dashboard-api/src/triggers/webhook.controller.ts`

## Задача
Реагировать на внешние события: PR открыт/обновлён, CI упал, issue помечен лейблом, комментарий
с командой.

## Критерии приёмки
- [ ] Проверка подписи вебхука обязательна; неподписанные запросы отклоняются.
- [ ] Событие транслируется в постановку прогона с идемпотентным ключом из id доставки
      (повторная доставка не создаёт второй прогон).
- [ ] Содержимое webhook трактуется как недоверенные данные (правила 1509 применяются и здесь):
      текст issue/комментария не является инструкцией для агента напрямую.
- [ ] Маппинг «событие → действие» настраивается на уровне проекта.

## Тесты
- E2E: подписанный и неподписанный вебхук; двойная доставка; настраиваемый маппинг.
