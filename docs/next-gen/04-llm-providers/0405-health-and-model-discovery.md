# 0405 — Health-check и дискавери моделей

**Фаза:** P0 · **Оценка:** S · **Зависит от:** 0401, 0402, 0403, 0404
**Файлы:** `packages/llm/src/registry/health.ts`

## Задача
Периодически опрашивать зарегистрированных провайдеров, кэшировать список моделей и
деградировать маршрутизацию вместо падения прогона.

## Объём
- `health()` у каждого адаптера: лёгкий запрос (`/v1/models`, `/api/tags`, минимальный ping).
- Кэш моделей с TTL и принудительным обновлением по команде.
- Статусы: `healthy | degraded | unavailable` + время последней успешной проверки.

## Критерии приёмки
- [ ] Недоступный локальный хост не роняет процесс и не блокирует другие провайдеры.
- [ ] Статус доступен через API (1906) и метрику.
- [ ] Health-опрос не создаёт нагрузку: интервал конфигурируем, запросы не параллелятся на одного провайдера.

## Тесты
- Юнит: провайдер отвечает/не отвечает/отвечает медленно; корректность кэша и TTL.
