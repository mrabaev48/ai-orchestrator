# 0406 — Ограничитель конкурентности на провайдера

**Фаза:** P0 · **Оценка:** S · **Зависит от:** 0304
**Файлы:** `packages/llm/src/transport/concurrency.ts`

## Контекст
Локальная модель — ресурс с жёстко ограниченной пропускной способностью (одна-две GPU).
При параллельных прогонах (группа 10) воркеры выстроятся в неуправляемую очередь и словят таймауты.

## Задача
Семафор на `providerId` с очередью ожидания и справедливым порядком.

## Объём
- `maxConcurrentRequests` из `ProviderRegistration`.
- Ожидание в очереди учитывает `AbortSignal` и общий дедлайн запроса.
- Метрики: `llm_provider_queue_depth`, `llm_provider_queue_wait_seconds`.

## Критерии приёмки
- [ ] При лимите 1 два одновременных запроса исполняются последовательно.
- [ ] Отмена в очереди освобождает слот немедленно.
- [ ] Ожидание в очереди не съедает таймаут генерации молча (учитывается отдельно и логируется).

## Тесты
- Юнит: лимит 1/2/N, отмена в очереди, таймаут ожидания.
