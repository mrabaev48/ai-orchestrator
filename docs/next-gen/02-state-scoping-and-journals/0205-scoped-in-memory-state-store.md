# 0205 — Скоупированный InMemoryStateStore

**Фаза:** P0 · **Оценка:** M · **Зависит от:** 0105
**Файлы:** `packages/state/src/in-memory/InMemoryStateStore.ts`

## Задача
Перевести in-memory адаптер на `Map<scopeKey, ProjectState>` и журналы по скоупу.

## Объём
- Ключ — `formatTenantScopeKey` из `packages/core/src/multitenancy-tenant-scope.ts`.
- Сохранить существующую проверку принадлежности шага скоупу
  (`InMemoryStateStore.ts:171`), но теперь по переданному скоупу, а не по текущему снимку.
- Ленивое создание пустого состояния для нового скоупа — управляется флагом, чтобы
  опечатка в `projectId` не создавала «фантомный» проект молча.

## Критерии приёмки
- [ ] Контрактный набор тестов (0202-стиль) проходит для обоих сторов одинаково.
- [ ] Обращение к несуществующему проекту без флага автосоздания даёт явную ошибку.

## Тесты
- Юнит: изоляция скоупов, ревизии, журналы, автосоздание вкл/выкл.

## Не входит
- Persistence.
