# 0208 — Проверка целостности состояния в скоупированном мире

**Фаза:** P0 · **Оценка:** S · **Зависит от:** 0207
**Файлы:** `packages/core/src/state-integrity.ts`, `packages/application/src/state-integrity-service.ts`

## Задача
Расширить проверки целостности: соответствие скоупа снимка и журналов, отсутствие «сирот»
(записи журнала без проекта в каталоге), непрерывность checksum-цепочки внутри проекта.

## Критерии приёмки
- [ ] Новые находки имеют явные коды и попадают в отчёт `check-state`.
- [ ] Проверка выполняется за один проход по журналам (без N+1 запросов).
- [ ] Существующие находки не изменили формат (обратная совместимость отчёта).

## Тесты
- Юнит: подмешанный шаг чужого проекта; разрыв checksum; журнал без проекта.

## Не входит
- Автоматический ремонт.
