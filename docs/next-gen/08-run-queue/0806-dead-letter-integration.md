# 0806 — Интеграция очереди с dead-letter и replay

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 0805
**Файлы:** `packages/execution/src/queue/dead-letter-handler.ts`, `.../replay-controller.ts`

## Контекст
Механизмы dead-letter и replay уже реализованы для отказов задач; очередь должна пользоваться
ими, а не заводить параллельный контур.

## Критерии приёмки
- [ ] Запись `dead` попадает в существующий DLQ с причиной и последней ошибкой.
- [ ] `replay-failure` умеет вернуть элемент в очередь (а не только перезапустить задачу напрямую).
- [ ] Повторная постановка из DLQ сохраняет исходный `idempotencyKey` или явно создаёт новый — решение зафиксировано в коде и тесте.

## Тесты
- Интеграция: исчерпание попыток → DLQ → replay → успешное выполнение.
