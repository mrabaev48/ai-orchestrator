# 0805 — Reaper просроченных лиз очереди

**Фаза:** P1 · **Оценка:** S · **Зависит от:** 0803
**Файлы:** `packages/execution/src/queue/lease-reaper.ts`

## Задача
Фоновая процедура: записи в статусе `leased` с истёкшим `lease_expires` возвращаются в `queued`
с задержкой и увеличенным `attempt`.

## Критерии приёмки
- [ ] Возврат идемпотентен: два reaper'а не увеличивают `attempt` дважды за одну просрочку.
- [ ] После `max_attempts` запись переходит в `dead` (интеграция с 0806).
- [ ] Метрика `queue_reaped_total`.

## Тесты
- Интеграция: убитый воркер → запись возвращается и подхватывается другим.
