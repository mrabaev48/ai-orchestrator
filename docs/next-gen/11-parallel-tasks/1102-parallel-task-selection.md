# 1102 — Выбор набора параллельных задач

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 1101
**Файлы:** `packages/workflow/src/task-selection.ts`

## Задача
Расширить выбор задачи до выбора совместимого набора размером ≤ `maxConcurrentRunsPerProject`.

## Критерии приёмки
- [ ] Набор всегда бесконфликтен по правилам 1101.
- [ ] При лимите 1 поведение идентично текущему (регрессия `tests/task-selection.test.ts`).
- [ ] Порядок внутри набора стабилен (приоритет, затем id) — детерминизм важен для воспроизводимости.

## Тесты
- Юнит: набор из 3 совместимых; исключение конфликтующей; лимит 1.
