# 1101 — Детектор конфликтов между задачами

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 0904
**Файлы:** `packages/workflow/src/conflicts/task-conflicts.ts`

## Контекст
`BacklogTask` уже несёт `affectedModules`, а `selectNextTask` выбирает ровно одну задачу
(`packages/workflow/src/index.ts`, `packages/execution/src/orchestrator.ts:248`).

## Задача
Консервативно определить, могут ли две задачи выполняться параллельно.

## Правила
- Пересечение `affectedModules` по префиксам путей → конфликт.
- Зависимость в графе backlog (прямая или транзитивная) → конфликт.
- Обе задачи мутируют одну базовую ветку → конфликт (снимается только merge-queue, 1104).
- Неизвестные/пустые `affectedModules` → считать конфликтующей (безопасный дефолт).

## Критерии приёмки
- [ ] Функция чистая и детерминированная.
- [ ] Безопасный дефолт при недостатке информации подтверждён тестом.

## Тесты
- Юнит-матрица: пересечение путей, транзитивная зависимость, пустые модули.
