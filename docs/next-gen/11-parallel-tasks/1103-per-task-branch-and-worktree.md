# 1103 — Своя ветка и worktree на задачу

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 1102, 0904
**Файлы:** `packages/execution/src/workspace-manager.ts`, `packages/execution/src/workspace/workspace-run-coordinator.ts`

## Контекст
`GitWorktreeWorkspaceManager` уже сериализует admin-операции git общим мьютексом
(`workspace-manager.ts:14-18`) — это защищает от известного класса повреждений worktree.
При параллельных задачах нагрузка на эти операции вырастет кратно.

## Задача
Гарантировать уникальность имени ветки и пути worktree на задачу и корректную очистку.

## Критерии приёмки
- [ ] Имя ветки включает `projectId`, `taskId`, короткий `runId` — коллизий нет.
- [ ] Мьютекс admin-операций дополняется межпроцессной lock-заявкой `repo:<id>` (0902).
- [ ] Очистка worktree выполняется и при аварийном завершении (TTL-prune уже есть).
- [ ] `tests/workspace-manager.test.ts` расширен на параллельные аллокации.

## Тесты
- Интеграция: 8 параллельных аллокаций на одном репозитории; проверка `git worktree list`.
