# 1105 — Ребейз и повторная верификация

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 1104
**Файлы:** `packages/execution/src/mutation/stages/verification.ts`, `packages/application/src/merge/rebase.ts`

## Задача
Перед интеграцией привести ветку к актуальной базе и повторно прогнать проверки
(lint/typecheck/test/build через существующий `run-verification-suite`).

## Критерии приёмки
- [ ] Ребейз выполняется в изолированном worktree, не трогая рабочие копии других задач.
- [ ] Повторная верификация обязательна: merged только после зелёных гейтов на новой базе.
- [ ] Число попыток ребейза ограничено (`maxRebaseAttempts`), затем — эскалация (1106).

## Тесты
- Интеграция: конфликтующие изменения → конфликт; непересекающиеся → успешный ребейз и merge.
