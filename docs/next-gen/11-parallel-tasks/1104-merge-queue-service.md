# 1104 — Merge queue для параллельных задач

**Фаза:** P1 · **Оценка:** L · **Зависит от:** 1103
**Файлы:** `packages/application/src/merge/merge-queue-service.ts`

## Задача
Последовательная интеграция веток параллельных задач в базовую: очередь на
`repo:<id>:branch:<base>`, по одной интеграции за раз.

## Объём
- Постановка ветки в merge-queue после успешной верификации задачи.
- Захват exclusive-заявки на базовую ветку на время интеграции.
- Состояния: `queued → rebasing → verifying → merged | conflicted | failed`.
- Все переходы фиксируются в evidence и в domain events.

## Критерии приёмки
- [ ] Две задачи, готовые одновременно, интегрируются строго последовательно.
- [ ] Интеграция не начинается без прохождения quality gates задачи.
- [ ] Отказ интеграции не теряет ветку — она остаётся доступной для ручного разбора.

## Тесты
- Интеграция на фикстурном репозитории: две ветки, последовательный merge.
