# 1604 — Репозиторий агентов и версионирование

**Фаза:** P2 · **Оценка:** M · **Зависит от:** 1602, 1603
**Файлы:** `packages/state/src/agents/agent.store.ts`

## Задача
CRUD-хранилище с семантикой версий: правка `draft` — на месте; публикация — фиксация новой
иммутабельной версии; удаление — перевод в `deprecated` (мягкое).

## Критерии приёмки
- [ ] `getPublished(agentId)` всегда возвращает последнюю опубликованную версию.
- [ ] `getExact(agentId, version)` доступен — нужно для воспроизведения прогонов по evidence.
- [ ] Удаление агента, назначенного проекту, отклоняется с указанием проектов.
- [ ] Контрактный набор проходит для in-memory и Postgres.

## Тесты
- Контрактный набор: черновики, публикация, депрекация, назначения.
