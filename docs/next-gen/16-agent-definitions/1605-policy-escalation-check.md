# 1605 — Проверка неэскалации прав агента

**Фаза:** P2 · **Оценка:** S · **Зависит от:** 0103, 1602
**Файлы:** `packages/application/src/agents/check-escalation.ts`

## Контекст
Создание агента не должно быть каналом обхода политики проекта. Права агента — пересечение
с проектными, а не объединение.

## Критерии приёмки
- [ ] `narrowToolPolicy(projectPolicy, agentPolicy)` вызывается при публикации и при каждом
      разрешении конфига прогона (двойная защита).
- [ ] Попытка расширить `writeMode`, снять `approvalRequiredActions` или поднять
      `autonomyCeiling` выше проектного отклоняется с точным указанием поля.
- [ ] Отказ фиксируется в audit log с актором.

## Тесты
- Юнит-матрица по каждому полю политики; интеграция: публикация «жадного» агента отклонена.
