# 1607 — Обобщённый рантайм декларативного агента

**Фаза:** P2 · **Оценка:** L · **Зависит от:** 1302, 1602, 1402
**Файлы:** `packages/agents/src/declarative/declarative-agent.ts`

## Задача
Одна реализация `AgentRole`, исполняющая любое определение: сборка контекста → вызов модели с
инструментами и схемой → исполнение вызовов → валидация финального ответа.

## Критерии приёмки
- [ ] Никакой кодогенерации: определение интерпретируется, публикация не требует пересборки.
- [ ] Все существующие гарантии (лимиты, отмена, evidence, гейты) работают без изменений.
- [ ] Лимиты агента пересекаются с проектными (минимум из двух), а не заменяют их.

## Тесты
- Интеграция на кассетах: определение из фикстуры проходит полный цикл до финального ответа.
