# 1608 — Компилятор определений и кэш

**Фаза:** P2 · **Оценка:** M · **Зависит от:** 1607
**Файлы:** `packages/agents/src/declarative/agent-compiler.ts`

## Задача
`compile(definition, deps) → AgentRole` с кэшем по `(agentId, version)` и инвалидацией при
депрекации.

## Критерии приёмки
- [ ] Компиляция не выполняет сетевых вызовов и детерминирована.
- [ ] Кэш общий на процесс, потокобезопасен для параллельных прогонов.
- [ ] Разные версии одного агента сосуществуют в кэше (нужно для активных прогонов).

## Тесты
- Юнит: кэш-хит/мисс; параллельная компиляция; инвалидация.
