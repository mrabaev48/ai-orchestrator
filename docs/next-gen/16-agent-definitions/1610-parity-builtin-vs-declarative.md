## Задача
Ворота на переключение по умолчанию: декларативная версия роли должна давать эквивалентный
результат на одинаковых входах и кассетах.

## Критерии приёмки
- [ ] Для каждой из 12 ролей: одинаковые входы → эквивалентный выход (сравнение по схеме, не побайтово).
- [ ] Число шагов и вызовов инструментов совпадает или меньше.
- [ ] Переключение источника ролей управляется флагом `ROLE_RUNTIME=builtin|declarative`.

## Тесты
- Параметризованный тест по всем ролям.
