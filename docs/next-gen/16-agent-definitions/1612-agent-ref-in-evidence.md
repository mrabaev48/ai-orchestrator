# 1612 — agentRef в evidence и в стоимости

**Фаза:** P2 · **Оценка:** S · **Зависит от:** 1607, 0606
**Файлы:** `packages/core/src/evidence/run-step-evidence.ts`, `packages/execution/src/persistence/run-step-recorder.ts`

## Задача
Записывать `agentId@version` в каждый шаг и в каждую запись стоимости — иначе после правки
агента невозможно понять, чем именно получен результат.

## Критерии приёмки
- [ ] Поле добавлено аддитивно (старые записи остаются валидными).
- [ ] Checksum-цепочка учитывает новое поле; миграция формата задокументирована.
- [ ] Read-модели и review-bundle показывают версию агента.

## Тесты
- Интеграция: прогон → в evidence и `run_cost` присутствует корректный `agent_ref`.
