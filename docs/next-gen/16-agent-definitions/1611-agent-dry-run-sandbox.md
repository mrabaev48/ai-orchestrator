# 1611 — Песочница dry-run для агента

**Фаза:** P2 · **Оценка:** M · **Зависит от:** 1607, 0310
**Файлы:** `packages/application/src/agents/dry-run.ts`

## Задача
Прогнать агента на фикстурном репозитории с mock/кассетным провайдером и вернуть полный трейс,
не касаясь реальных проектов.

## Объём
- Переиспользовать `tests/support/scratch-git-repo.ts` как генератор фикстур.
- Принудительный `writeMode: 'sandbox-write'` и запрет внешних side-effects независимо от определения.
- Результат: шаги, вызовы инструментов, стоимость, финальный вывод, найденные проблемы.

## Критерии приёмки
- [ ] Dry-run физически не может выполнить push/PR или запись вне песочницы.
- [ ] Результат сохраняется и доступен по API (1907).
- [ ] Время выполнения ограничено жёстким таймаутом.

## Тесты
- Интеграция: агент, пытающийся сделать push, получает отказ политики.
