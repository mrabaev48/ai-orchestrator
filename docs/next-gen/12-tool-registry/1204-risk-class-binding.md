# 1204 — Привязка класса риска к гейтам

**Фаза:** P2 · **Оценка:** M · **Зависит от:** 1202
**Файлы:** `packages/core/src/policy/risk-classification.ts`, `packages/execution/src/steps/step-policy-gate.ts`

## Задача
Связать `ToolDescriptor.riskClass` с существующей матрицей классификации риска и правилами
approvals, чтобы новый (в т.ч. внешний) инструмент автоматически попадал под нужный гейт.

## Критерии приёмки
- [ ] Инструмент без явного класса считается `write_external` и требует approval (безопасный дефолт).
- [ ] Понижение класса возможно только явной настройкой оператора, и оно логируется в audit.
- [ ] `tests/risk-classification-matrix.test.ts` расширен новыми случаями.

## Тесты
- Юнит: каждый класс → ожидаемое решение гейта; неизвестный инструмент → approval.
