# 1205 — Экспорт схем инструментов в формат модели

**Фаза:** P2 · **Оценка:** S · **Зависит от:** 1202
**Файлы:** `packages/tools/src/registry/to-tool-spec.ts`

## Задача
Преобразование `ToolDescriptor → ToolSpec` (0301) с учётом ограничений strict-схем провайдеров.

## Объём
- Генерация JSON Schema из zod через `z.toJSONSchema()` (в проекте zod 4.4.3 — метод доступен).
- Для strict-режимов: все поля в `required`, `additionalProperties:false`;
  проверка `assertStrictSchemaCompatible` (0307) при экспорте.
- Усечение длинных описаний до лимита провайдера с сохранением смысла.

## Критерии приёмки
- [ ] Схемы всех 13 локальных инструментов проходят strict-проверку.
- [ ] Имена инструментов валидны для всех провайдеров (без `:` там, где он запрещён — предусмотреть кодирование для `mcp:*`).

## Тесты
- Юнит: экспорт каждого инструмента; отказ на несовместимой схеме; кодирование имени MCP-инструмента.
