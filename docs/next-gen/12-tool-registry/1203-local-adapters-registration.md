# 1203 — Регистрация локальных адаптеров в реестре

**Фаза:** P2 · **Оценка:** S · **Зависит от:** 1202
**Файлы:** `packages/tools/src/index.ts`

## Задача
Перевести `createLocalToolSet` на реестр: 13 существующих инструментов регистрируются как
дескрипторы с их схемами, метаданными детерминизма и классом риска.

## Критерии приёмки
- [ ] Поведение `execute` для существующих инструментов не изменилось (регрессия).
- [ ] Политика (`allowedWritePaths`, `writeMode`, `protectedWritePaths`, `maxModifiedFiles`)
      применяется на прежнем уровне — реестр её не обходит.
- [ ] Существующие evidence-записи не изменили формат.
