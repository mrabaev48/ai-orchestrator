# 1303 — Наблюдения как сообщения роли tool

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 1302
**Файлы:** `packages/execution/src/roles/role-runner.ts`

## Задача
Вместо накопления массива и повторной сериализации в промпт — добавлять результат инструмента
отдельным сообщением (`role: 'tool'`, `toolCallId`), сохраняя историю диалога.

## Критерии приёмки
- [ ] Рост контекста линейный по числу шагов (замер в тесте: токены шага N растут не быстрее O(N)).
- [ ] Ошибка инструмента передаётся с явным флагом (у Anthropic — `is_error` в `tool_result`).
- [ ] Формат evidence не изменился.

## Тесты
- Юнит: сборка сообщений после 5 шагов; сравнение объёма с текущей реализацией.
