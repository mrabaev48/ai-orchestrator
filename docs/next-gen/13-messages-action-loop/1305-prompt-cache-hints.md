# 1305 — Подсказки кэширования промпта

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 1303, 0404
**Файлы:** `packages/execution/src/roles/role-runner.ts`, `packages/llm/src/adapters/anthropic.ts`

## Задача
Пометить стабильный префикс (системные инструкции агента, enforced-правила, определения
инструментов) как кэшируемый и убедиться, что он действительно не меняется между шагами.

## Документация
- Anthropic: `cache_control: {type:'ephemeral'}` (опц. `ttl:'1h'`), максимум 4 явных брейкпоинта,
  минимальная длина кэшируемого префикса зависит от модели; usage возвращает
  `cache_creation_input_tokens` и `cache_read_input_tokens`. Кэш инвалидируется при изменении
  определений инструментов и `tool_choice` — значит, набор инструментов должен быть стабилен в рамках шага.

## Критерии приёмки
- [ ] В цикле из 5 шагов доля `cache_read` токенов растёт (замер на кассетах реальных ответов).
- [ ] Префикс байт-в-байт стабилен между шагами (тест на равенство).
- [ ] Экономия видна в `run_cost` (кэш-токены по своей цене).

## Тесты
- Интеграция на кассетах с cache-usage; юнит на стабильность префикса.
