# 1304 — Сжатие старых наблюдений

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 1303
**Файлы:** `packages/execution/src/roles/observation-compaction.ts`

## Задача
Держать последние N наблюдений полностью, более ранние — в сжатом виде (краткое резюме
результата инструмента: статус, ключевые поля, размер вывода), чтобы влезать в контекст
локальных моделей.

## Критерии приёмки
- [ ] Полный вывод инструмента всегда остаётся в evidence — сжатие касается только контекста модели.
- [ ] Порог N и бюджет токенов конфигурируемы на уровне агента.
- [ ] Сжатие детерминировано (без вызова LLM на первом этапе).

## Тесты
- Юнит: 20 наблюдений → бюджет соблюдён; evidence полон; детерминизм при повторе.
