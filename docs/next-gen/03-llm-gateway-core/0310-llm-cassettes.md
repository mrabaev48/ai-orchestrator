# 0310 — Кассеты запись/воспроизведение ответов LLM

**Фаза:** P0 · **Оценка:** M · **Зависит от:** 0304
**Файлы:** `packages/llm/src/testing/cassette.ts`, `tests/support/llm-cassettes/`

## Контекст
Без детерминированных ответов тесты новых слоёв (агенты, MCP, action loop) будут либо
флаки, либо дорогими. Существующий `MockLlmClient` возвращает очередь объектов и не
воспроизводит реальную форму ответов провайдеров.

## Задача
Реализовать провайдер-обёртку с режимами `record` / `replay` / `passthrough` и хранилищем
кассет в репозитории.

## Объём
- Ключ кассеты — хеш от `(modelRef, нормализованные messages, tools, responseSchema)`.
- Запись включает `usage`, `finishReason`, задержку; секреты вырезаются при записи.
- В `replay` отсутствие кассеты — ошибка (никаких молчаливых обращений в сеть в CI).

## Критерии приёмки
- [ ] Прогон e2e-сценария в `replay` не делает сетевых вызовов.
- [ ] Кассеты читаемы (JSON) и ревьюабельны в PR.
- [ ] Режим по умолчанию в CI — `replay`.

## Тесты
- Самотест: запись против mock-сервера, затем воспроизведение и сверка.
