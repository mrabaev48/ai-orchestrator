# 0308 — Repair-проход при невалидном JSON

**Фаза:** P0 · **Оценка:** S · **Зависит от:** 0307
**Файлы:** `packages/llm/src/structured/repair.ts`

## Контекст
`RoleRunner` уже делает один повтор при провале валидации схемы
(`packages/execution/src/roles/role-runner.ts:180`), но повтор идёт «вслепую» — без текста ошибки.

## Задача
Один целевой repair-запрос: исходный ответ + конкретные ошибки валидации + требование вернуть
только корректный JSON.

## Критерии приёмки
- [ ] Ровно одна попытка ремонта; вторая неудача → `SchemaValidationError` (существующий контракт).
- [ ] Токены repair-запроса учитываются в стоимости отдельным тегом `source: 'schema_repair'`.
- [ ] Метрика `schema_repair_total{model, strategy, outcome}`.

## Тесты
- Юнит: обрезанный JSON, лишние поля, неверный тип; успешный и неуспешный ремонт.
