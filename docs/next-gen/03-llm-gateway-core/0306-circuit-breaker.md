# 0306 — Circuit breaker на провайдера

**Фаза:** P0 · **Оценка:** S · **Зависит от:** 0305
**Файлы:** `packages/llm/src/transport/circuit-breaker.ts`

## Задача
Не долбить упавший провайдер: при N ошибках за окно переводить его в `open` на cooldown,
чтобы маршрутизатор сразу шёл к следующему кандидату.

## Объём
- Состояния `closed | open | half-open`, счётчик по окну, пробный запрос в `half-open`.
- Состояние — на `providerId`, не на модель.
- Метрика `llm_circuit_state` (gauge) с тегами `provider`, `state`.

## Критерии приёмки
- [ ] В состоянии `open` вызов не уходит в сеть и возвращает `kind: 'server'` с пометкой breaker.
- [ ] Один успешный пробник закрывает цепь; неуспешный продлевает cooldown.
- [ ] Поведение детерминировано в тестах (инъекция часов).

## Тесты
- Юнит с управляемым временем: переходы состояний, cooldown, пробник.
