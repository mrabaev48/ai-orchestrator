# 1007 — Нагрузочный профиль параллельного исполнения

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 1004, 0904
**Файлы:** `tests/load/parallel-runs.load.test.ts` (новый)

## Задача
Расширить существующий load-набор (`tests/load/autonomous-run.load.test.ts`) на сценарий
«20 одновременных прогонов, 5 проектов».

## Проверяемые инварианты
- Ни одного нарушения инвариантов состояния.
- Ни одного дублирующегося side-effect (push/PR) — по dedup-реестру.
- Все элементы очереди обработаны ровно один раз.
- p95 времени ожидания в очереди в пределах порога.

## Критерии приёмки
- [ ] Тест воспроизводим и запускается в CI по метке (не в каждом PR).
- [ ] Отчёт содержит распределение по проектам и глубину очереди во времени.

## Тесты
- Сам тест является артефактом.
