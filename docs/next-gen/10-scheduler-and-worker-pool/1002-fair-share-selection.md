# 1002 — Справедливое распределение между проектами

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 1001, 0803
**Файлы:** `packages/application/src/scheduling/fair-share.ts`

## Задача
Не дать одному «жадному» проекту занять весь пул: weighted round-robin поверх выборки из очереди.

## Объём
- Учитывать веса проектов и число уже активных прогонов проекта.
- Голодание исключается: проект, не получавший слот дольше порога, повышается в приоритете.
- Выборка кандидатов из очереди с фильтром по проекту (индекс из 0801).

## Критерии приёмки
- [ ] При равных весах и насыщенной очереди распределение слотов между проектами ±10%.
- [ ] Проект с весом 2 получает вдвое больше слотов, чем с весом 1.
- [ ] Ни один проект не голодает дольше настроенного порога.

## Тесты
- Симуляция на 1000 итераций с проверкой распределения.
