# 1005 — Мягкое завершение и дренаж

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 1004
**Файлы:** `apps/worker/src/main.ts`, `apps/worker/src/worker-pool.ts`

## Задача
По SIGTERM/SIGINT: перестать забирать работу → дать текущим шагам завершиться в пределах
таймаута → отменить оставшиеся через `AbortSignal` → освободить лизы очереди и ресурсов → выйти.

## Критерии приёмки
- [ ] Незавершённый элемент возвращается в очередь (`requeue`), а не остаётся `leased` до TTL.
- [ ] Все ресурсные лизы освобождены (проверяется после теста).
- [ ] Существующая механика `propagate-abort` и recovery-checkpoints переиспользована.
- [ ] Код выхода 0 при штатном дренаже.

## Тесты
- Интеграция: SIGTERM в середине прогона → элемент возвращён, checkpoint записан, лизы свободны.
