# 1008 — Chaos: убийство воркера в середине мутации

**Фаза:** P1 · **Оценка:** M · **Зависит от:** 1005, 0806
**Файлы:** `tests/chaos/worker-kill.chaos.test.ts` (новый)

## Задача
Проверить главный риск параллелизма: аварийная смерть воркера между «сделал side-effect» и
«записал результат».

## Сценарий
1. Прогон доходит до стадии commit/push (mutation pipeline).
2. Процесс-исполнитель принудительно завершается.
3. Reaper возвращает элемент в очередь, другой воркер подхватывает.
4. Проверить: side-effect не повторён (dedup-registry), состояние консистентно,
   evidence содержит обрыв и возобновление.

## Критерии приёмки
- [ ] Дублирующего push/PR нет ни в одном из 20 прогонов сценария.
- [ ] Состояние проходит `check-state` без находок уровня blocker.
