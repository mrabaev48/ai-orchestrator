# 2701 — Поддержка эмбеддингов в LLM Gateway

**Фаза:** P4 · **Оценка:** M · **Зависит от:** 0304
**Файлы:** `packages/llm/src/embeddings/*`

## Задача
Добавить в gateway операцию `embed(texts)` с теми же гарантиями (маршрутизация, лимиты,
usage/cost, offline-профиль), вместо отдельного клиента.

## Объём
- OpenAI-compatible `/v1/embeddings`; Ollama `/api/embed`.
- Батчинг с ограничением размера запроса; нормализация размерности в дескрипторе модели.

## Критерии приёмки
- [ ] Локальная модель эмбеддингов работает в offline-профиле.
- [ ] Стоимость эмбеддингов учитывается в `run_cost` с отдельным `source`.

## Тесты
- Юнит на фикстурах обоих API; батчинг; ошибка размерности.
