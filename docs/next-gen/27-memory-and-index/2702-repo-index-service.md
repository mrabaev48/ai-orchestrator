# 2702 — Индекс репозитория

**Фаза:** P4 · **Оценка:** L · **Зависит от:** 2701
**Файлы:** `packages/application/src/index/repo-index-service.ts`

## Задача
Строить и инкрементально обновлять индекс кода (символы + семантические фрагменты), чтобы
контекст собирался точечно, а не «прочитать полрепозитория».

## Критерии приёмки
- [ ] Инкрементальное обновление по diff, а не полная переиндексация.
- [ ] Индекс скоупирован проектом и не пересекается между проектами.
- [ ] Поиск по индексу доступен агенту как инструмент с классом риска `read`.
- [ ] Отсутствие индекса не ломает прогон (деградация к текущему поиску `search_repo`).

## Тесты
- Интеграция на фикстурном репозитории: построение, инкремент, поиск.
