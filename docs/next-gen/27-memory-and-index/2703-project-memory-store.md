# 2703 — Долговременная память проекта

**Фаза:** P4 · **Оценка:** M · **Зависит от:** 2701
**Файлы:** `packages/state/src/memory/project-memory.store.ts`

## Задача
Хранить извлечённые уроки: архитектурные решения, конвенции, повторяющиеся грабли —
с источником, датой и ссылкой на прогон.

## Контекст
Часть механики уже есть: `FailureRecord` превращается в ограничения промпта
(`packages/prompts/src/prompt-pipeline.ts:39-41`). Память — обобщение этого приёма.

## Критерии приёмки
- [ ] Каждая запись памяти имеет провенанс (прогон, шаг, актор) — иначе её нельзя оспорить.
- [ ] Запись может быть помечена устаревшей и перестаёт попадать в контекст.
- [ ] Память скоупирована проектом.

## Тесты
- Юнит на хранилище; интеграция: урок из прогона A влияет на контекст прогона B.
