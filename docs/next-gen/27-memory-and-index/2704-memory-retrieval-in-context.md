# 2704 — Извлечение памяти в контекст

**Фаза:** P4 · **Оценка:** M · **Зависит от:** 2703, 1402
**Файлы:** `packages/capabilities/src/context/memory-retrieval.ts`

## Задача
Добавить блок памяти в сборщик контекста (позиция 8 по приоритету) с отбором по релевантности
задаче и жёстким бюджетом.

## Критерии приёмки
- [ ] Память никогда не вытесняет системные инструкции и enforced-правила.
- [ ] Каждая включённая запись памяти фиксируется в evidence — видно, что повлияло на решение.
- [ ] Отбор детерминирован при одинаковом входе.

## Тесты
- Юнит: бюджет, приоритет, детерминизм; интеграция: релевантная запись попадает в контекст.
