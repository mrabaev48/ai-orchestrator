# 1506 — Обнаружение инструментов и неймспейсинг

**Фаза:** P2 · **Оценка:** M · **Зависит от:** 1505, 1202
**Файлы:** `packages/capabilities/src/mcp/discovery.ts`

## Задача
`listTools()` сервера → `ToolDescriptor[]` с именем `mcp:<serverId>:<toolName>`.

## Объём
- Пагинация `tools/list` (SDK возвращает страницы с курсором) — собрать все страницы.
- Фильтрация по `allowedTools` регистрации.
- Кэш каталога с TTL и принудительным обновлением.
- Схема входа берётся из `inputSchema` инструмента MCP; при отсутствии — инструмент помечается
  недоступным для моделей со строгими схемами.

## Критерии приёмки
- [ ] Коллизий с локальными именами нет (проверяется тестом).
- [ ] Инструмент вне allow-list не появляется в каталоге агента.
- [ ] Сервер без capability `tools` обрабатывается корректно (пустой список, не ошибка).

## Тесты
- Интеграция: сервер с 3 инструментами и пагинацией; allow-list; сервер без tools.
