# 1505 — Пул соединений и жизненный цикл MCP

**Фаза:** P2 · **Оценка:** M · **Зависит от:** 1503, 1504
**Файлы:** `packages/capabilities/src/mcp/connection-pool.ts`

## Задача
Одно соединение на `(tenantId, serverId)` с ленивым стартом, idle-таймаутом и переиспользованием
между прогонами — иначе каждый шаг агента будет поднимать процесс заново.

## Критерии приёмки
- [ ] Параллельные прогоны переиспользуют одно соединение; конкурентные вызовы сериализуются
      или мультиплексируются согласно возможностям транспорта.
- [ ] Idle-соединение закрывается по таймауту, освобождая ресурсы.
- [ ] Graceful shutdown воркера (1005) закрывает все соединения.

## Тесты
- Интеграция: 10 параллельных вызовов через один пул; idle-закрытие; shutdown.
