# 1510 — Фикстурный MCP-сервер и тестовый набор

**Фаза:** P2 · **Оценка:** M · **Зависит от:** 1503, 1504
**Файлы:** `tests/support/mcp-fixture-server.ts` (новый)

## Задача
Собственный минимальный MCP-сервер на том же SDK для детерминированных тестов
(stdio и HTTP режимы).

## Объём
- Инструменты: `echo` (read), `write_file` (write_external), `slow` (таймаут),
  `boom` (ошибка), `hostile` (инъекция в выводе), `paged` (много инструментов для пагинации).
- Управление поведением через аргументы запуска.

## Критерии приёмки
- [ ] Сервер запускается и в stdio, и в HTTP-режиме из тестов.
- [ ] Все тесты MCP-группы используют этот фикстур, без обращения к внешним серверам.
- [ ] Процесс сервера гарантированно завершается после теста.

## Тесты
- Самотест фикстура + использование в 1503–1509.
