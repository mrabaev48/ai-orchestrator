# 1508 — Классы риска и approvals для MCP-инструментов

**Фаза:** P2 · **Оценка:** S · **Зависит от:** 1507, 1204
**Файлы:** `packages/capabilities/src/mcp/risk.ts`

## Задача
Безопасный дефолт: инструмент неизвестного риска = `write_external` + обязательный approval.
Понижение класса — только явным `riskOverrides` оператора.

## Критерии приёмки
- [ ] Впервые обнаруженный инструмент требует approval при первом вызове.
- [ ] `riskOverrides` фиксируется в audit log с указанием актора.
- [ ] Эвристики по имени инструмента (`delete`, `write`, `deploy`) только повышают класс, никогда не понижают.

## Тесты
- Юнит: новый инструмент → approval; override → пониженный класс + запись в audit.
