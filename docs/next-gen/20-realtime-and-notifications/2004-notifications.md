# 2004 — Уведомления (Slack / Telegram / email)

**Фаза:** P3 · **Оценка:** M · **Зависит от:** 2001
**Файлы:** `packages/application/src/notifications/*`

## Задача
Каналы уведомлений для событий, требующих человека: approval, блокировка, превышение бюджета,
провал merge.

## Критерии приёмки
- [ ] Каналы подключаются как данные (креды через `CredentialStore`).
- [ ] Дедупликация: одно и то же событие не рассылается дважды.
- [ ] Тихие часы и группировка (не более N сообщений в минуту на канал).
- [ ] Уведомление содержит ссылку на прогон в UI, но не содержит содержимого кода/секретов.

## Тесты
- Юнит: дедупликация, троттлинг; интеграция с фиктивным транспортом.
