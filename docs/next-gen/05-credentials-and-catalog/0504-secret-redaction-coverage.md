# 0504 — Расширение редакции секретов на провайдеров

**Фаза:** P0 · **Оценка:** S · **Зависит от:** 0503
**Файлы:** `packages/shared/src/config/runtime-config.ts`, `packages/tools/src/secrets/redaction.ts`

## Контекст
Механизм редакции уже есть (`registerRuntimeSecrets` + `redactSecrets`, регулярки под `sk-…`,
`bearer …`), но он рассчитан на один ключ из env.

## Задача
Регистрировать любой выданный `CredentialStore.get` секрет в реестре редакции на время процесса
и покрыть форматы ключей основных провайдеров.

## Критерии приёмки
- [ ] Секрет, полученный из хранилища, немедленно попадает в реестр редакции.
- [ ] Добавлены паттерны: `sk-ant-…`, `AIza…`, `hf_…`, JWT-подобные строки.
- [ ] Существующий тест `tests/secret-redaction-and-audit.test.ts` расширен и зелёный.

## Тесты
- Юнит: лог с ключом каждого формата → `<redacted>`; evidence-запись без секретов.
