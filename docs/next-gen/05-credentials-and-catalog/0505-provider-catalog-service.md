# 0505 — Сервис каталога провайдеров и моделей

**Фаза:** P0 · **Оценка:** M · **Зависит от:** 0304, 0405, 0502
**Файлы:** `packages/application/src/providers/provider-catalog-service.ts`

## Задача
Use-case уровень: зарегистрировать провайдера, проверить доступность, обновить каталог моделей,
включить/выключить, удалить.

## Объём
- `registerProvider(scope, input)` → валидация + сохранение креда через `CredentialStore` + health-check.
- `refreshModels(scope, providerId)` → `listModels()` адаптера → запись в `models`.
- `listAvailableModels(scope)` → агрегированный каталог с health-статусом.
- Ошибки регистрации не сохраняют провайдера в enabled-состоянии.

## Критерии приёмки
- [ ] Регистрация локального провайдера без ключа проходит успешно.
- [ ] Недоступный провайдер регистрируется, но помечается `unavailable` (не отклоняется).
- [ ] Все операции пишутся в immutable audit log.

## Тесты
- Интеграция с mock- и fake-http адаптерами: успешная регистрация, недоступный хост, обновление моделей.
