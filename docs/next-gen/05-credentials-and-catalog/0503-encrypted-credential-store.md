# 0503 — Шифрованное хранилище кредов (AES-256-GCM)

**Фаза:** P0 · **Оценка:** M · **Зависит от:** 0501, 0502
**Файлы:** `packages/state/src/credentials/postgres-credential.store.ts`

## Задача
Реализация `CredentialStore` на Postgres с шифрованием на мастер-ключе из окружения/KMS.

## Объём
- `node:crypto` AES-256-GCM; уникальный nonce на запись; аутентификационный тег хранится с шифротекстом.
- Мастер-ключ: `SECRETS_MASTER_KEY` (base64, ≥32 байта) + `key_id` для ротации ключа.
- `fingerprint` — SHA-256 от значения, усечённый, для отображения в UI без раскрытия.
- Ротация: перешифровка записей под новым `key_id` отдельной командой.

## Критерии приёмки
- [ ] Отсутствие/короткий мастер-ключ → hard-fail на старте (в стиле существующего `ConfigError`).
- [ ] Значение не логируется ни при каком уровне логирования (проверяется тестом с перехватом логов).
- [ ] Расшифровка чужого тенанта невозможна (скоуп в ключе запроса).

## Тесты
- Юнит: шифрование/расшифровка, порча тега → ошибка, ротация ключа, изоляция тенантов.
